# Tags & Tag Roles

## Tags

A simple, flexible label you attach to members and small groups — "Worship Team," "First Responders,"
"Youth Leader," anything your church finds useful. Create tags once under **Settings →
Tags**, then pick them from a chip picker on any member's record. There's no limit to how
you use them beyond members, and no colors or scoping — a tag is just a tag, shared across
your whole church.

## Tag Roles

Different churches call the same job different things — one calls their small-group leader
a "Leader," another a "Coach," another a "Guide." **Tag Roles** let you map *your* church's
own tag onto a fixed set of built-in functions, so pickers throughout the app can filter to
"whoever does this job" using your own vocabulary.

Under **Settings → Tag roles**, map a tag to each function you use:

| Function | Where it's used |
|---|---|
| Small group leader | The Leader picker on [Small Groups](#/groups) |
| Small group supervisor | The Supervisor picker on Small Groups |
| Ministry leader | The Leader picker on [Ministries](#/ministries) |
| Visitor follow-up | The "Assigned to" picker on [Visitors](#/visitors) |

If a function isn't mapped to a tag, its picker simply shows every active member instead of
filtering — mapping these is entirely optional, and nothing breaks if you skip it.

## Creating a tag on the spot

Every tag picker ends with **＋ New tag**: type the name and press Enter. The tag is created
and selected right away, no need to go to Settings first.

## Tagging many people at once

On the [Members](#/members) list (and on [Small Groups](#/groups)), **Tag…** adds or removes one
tag on **everyone the list is showing right now**. Search or filter first — for example, filter
by a ministry's tag or by status — then choose the tag, **Add this tag** or **Remove this tag**,
and **Apply**. People's other tags are never touched.

## Merging two tags

Two tags that mean the same thing ("Youth" and "Young people")? In **Settings → Tags**, click
**Merge into…** on the one to remove and pick the one to keep. Everyone with the first tag gets
the second, Tag Roles that used it switch over, and the first tag is deleted. This can't be
undone.

## Tags on groups

Small groups can carry tags too, and the groups list can be filtered by tag.
